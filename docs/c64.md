# Commodore 64 (C64) Technical Documentation

This document describes the memory map, MOS 6510 CPU $00/$01 banking control, and software setup implemented in `Machines.C64` and `Host.C64`.

---

## 1. Memory Map & 6510 Banking

| Address Range | Size | Component / Purpose |
|---|---|---|
| `$0000–$0001` | 2 B | MOS 6510 On-Chip I/O Port ($00 Dir, $01 Data) |
| `$0002–$9FFF` | 40 KB | Main System RAM |
| `$A000–$BFFF` | 8 KB | BASIC 2.0 ROM (Selectable via LORAM) |
| `$C000–$CFFF` | 4 KB | Free RAM / RAM Expansion |
| `$D000–$DFFF` | 4 KB | Character ROM / I/O Regs (VIC-II, SID, CIA1, CIA2) |
| `$E000–$FFFF` | 8 KB | KERNAL OS ROM (Selectable via HIRAM) |

---

## 2. 6510 On-Chip I/O Port ($0001) Control Bits

* **Bit 0 (`LORAM`)**: 1 = BASIC ROM at `$A000–$BFFF`, 0 = RAM.
* **Bit 1 (`HIRAM`)**: 1 = KERNAL ROM at `$E000–$FFFF`, 0 = RAM.
* **Bit 2 (`CHAREN`)**: 1 = I/O Area at `$D000–$DFFF`, 0 = Character ROM.
